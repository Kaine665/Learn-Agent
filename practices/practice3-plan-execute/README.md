# 实践3：Plan-and-Execute Agent

## 目标

学习规划与执行模式，解决 ReAct 在长任务中的稳定性问题。

## 核心概念

### Plan-and-Execute 模式

与 ReAct 的"边想边做"不同，Plan-and-Execute 是"先规划再执行"：

```
Plan（规划） → Execute（执行） → Evaluate（评估） → Refine（调整）
```

### 为什么需要规划？

**ReAct 的问题：**
- 对于长任务，容易迷失方向
- 缺少整体视角
- 可能重复执行相同步骤

**规划的优势：**
- 先看全局，再执行细节
- 任务分解清晰
- 执行过程可控

### 规划流程

1. **任务分解**：将大任务分解为子任务
2. **计划生成**：生成执行计划
3. **计划执行**：按计划逐步执行
4. **计划调整**：根据执行结果调整计划

## 设计思路

### 1. 两阶段架构

```python
class PlanAndExecuteAgent:
    def plan(self, goal: str) -> List[str]:
        """规划阶段：生成任务计划"""
        pass
    
    def execute(self, plan: List[str]) -> str:
        """执行阶段：按计划执行"""
        pass
```

### 2. 计划格式

计划可以是简单的任务列表：

```
计划：
1. 搜索相关信息
2. 整理搜索结果
3. 生成报告
4. 优化报告格式
```

### 3. 计划执行

执行每个步骤，并记录结果：

```python
for step in plan:
    result = execute_step(step)
    record_result(step, result)
```

### 4. 计划调整

如果执行过程中发现问题，可以：
- 重新规划
- 调整后续步骤
- 跳过某些步骤

## 实现要点

1. **规划 Prompt**：设计专门用于规划的 Prompt
2. **计划解析**：解析 LLM 生成的计划
3. **步骤执行**：逐个执行计划步骤
4. **计划调整**：根据执行结果动态调整计划
5. **完成判断**：判断计划是否全部完成

## 运行示例

```bash
python example.py
```

示例任务：
- "写一篇关于 AI 的短文"
- "分析某个主题并生成报告"
- "完成一个多步骤的研究任务"

## 学习重点

通过这个实践，你将理解：

1. ✅ **规划的重要性**：为什么长任务需要规划？
2. ✅ **计划生成**：如何让 LLM 生成可执行的计划？
3. ✅ **计划执行**：如何按计划逐步执行？
4. ✅ **计划调整**：如何处理计划执行中的意外？

## 对比：ReAct vs Plan-and-Execute

| 特性 | ReAct | Plan-and-Execute |
|------|-------|------------------|
| 适用场景 | 动态任务、搜索 | 长任务、结构化任务 |
| 稳定性 | 中等 | 高 |
| 灵活性 | 高 | 中等 |
| 执行方式 | 边想边做 | 先规划再执行 |
