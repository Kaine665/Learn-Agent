# 实践5：反思机制 Agent

## 目标

学习如何为 Agent 添加反思能力，让 Agent 能够自我评估、错误恢复和结果优化。

## 核心概念

### 反思机制（Reflection）

反思是现代 Agent 的突破能力，包括：

1. **自我检视（Self-Critique）**
   - Agent 自动检查自己的回答是否合理
   - 检查是否违反规则
   - 检查逻辑是否一致

2. **错误恢复（Error Recovery）**
   - 当工具调用失败时，自动重试或改用其他方法
   - 根据错误信息调整策略

3. **结果优化（Self-Refine）**
   - Agent 可以对初稿自动完善
   - 重构写作、优化代码、精炼结构

### 反思循环

```
执行 → 反思 → 评估 → 修正 → 再执行 → ...
```
