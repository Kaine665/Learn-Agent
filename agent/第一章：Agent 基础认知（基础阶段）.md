# 第一章：Agent 基础认知（基础阶段）

## 本章目标

- 理解 Agent 的本质
- 理解 Agent 与传统程序的区别
- 掌握 Agent 的基本组成部分
- 建立后续学习（架构、工具使用、规划等）的认知框架

---

## 1. 什么是 Agent？（基础定义）

### 1.1 Agent 的标准定义

Agent（智能体）是一种能够：

- **感知环境**（Perception）
- **做出决策**（Decision Making）
- **采取行动**（Action）

的自主实体。

它可以是软件（AI Agent）、机器人、游戏 NPC，甚至自动化工作流。

### 1.2 Agent = 感知 + 决策 + 执行

一个最简单的公式：

```
Agent = Sensor（感知） + Policy（策略） + Action（执行）
```

### 1.3 与传统程序的区别

| 特点 | 传统程序 | AI Agent |
|------|---------|----------|
| 行为方式 | 固定逻辑 | 动态推理 |
| 输入处理 | 明确规则 | 自主理解 |
| 目标 | 程序员定义所有步骤 | 定义目标，让 Agent 自行探索步骤 |
| 适应性 | 差 | 强 |
| 环境交互 | 受限 | 多工具、多环境交互 |

**一句话总结区别：**

传统程序"按步骤执行"，Agent"按目标思考并行动"。

---

## 2. Agent 的三大特征（基础认知核心）

### 2.1 自主性（Autonomy）

Agent 可以根据目标自主决定下一步，不依赖人工指令。

**例：**

你让 Agent"收集某个行业报告"，它会：

```
搜索 → 过滤 → 结构化 → 输出
```

而不是只执行一个固定 API。

### 2.2 目标导向（Goal-Oriented）

Agent 不是处理指令，而是实现目标。

**例：**

与其告诉 Agent "访问 3 个网站"，

不如直接说"帮我找到可用的市场数据"。

### 2.3 环境交互（Environment Interaction）

Agent 会根据外部反馈调整行为，形成闭环。

**例：**

某 API 报错 → Agent 改用其他方法。

## 3. Agent 的基础架构（核心知识）

标准 Agent 包含四个模块：

```
┌──────────┐
│ 感知 Perception │ ← 输入（用户、环境）
└─────┬────┘
      │
┌─────▼──────┐
│ 决策 Decision │（推理、规划）
└─────┬──────┘
      │
┌─────▼──────┐
│ 执行 Action │（工具调用、生成结果）
└─────┬──────┘
      │
┌─────▼──────┐
│ 记忆 Memory │（保存经验）
└──────────┘
```

### 每个模块的作用

#### 3.1 感知（Perception）

理解输入信息，包括：

- 用户指令
- 环境状态（如 API 输出）
- 上下文历史记录

这是 Agent 的"眼睛"。

#### 3.2 决策（Decision Making）

决定应该做什么，包括：

- 推理（ReAct）
- 规划（Plan-and-Execute）
- 策略选择

这是 Agent 的"大脑"。

#### 3.3 执行（Action）

完成实际任务：

- 工具调用（API、搜索、数据库）
- 与外部系统交互
- 产生输出

这是 Agent 的"手脚"。

#### 3.4 记忆（Memory）

包括：

- 短期记忆（当前任务上下文）
- 长期记忆（历史经验）

这是 Agent 的"记忆体"。

## 4. Agent 的基本类型（基础分类）

### 4.1 反应式 Agent（Reactive Agent）

**特点：** 基于规则，看到输入立即反应。

**适合简单任务，如：**

- 温控系统
- 游戏 NPC

**弱点：** 无长远规划。

### 4.2 目标导向 Agent（Goal-Based Agent）

**特点：** 根据目标设计行动路径。

**优点：**

- 可规划
- 可推理

是最常用的 AI Agent 类型。

### 4.3 学习型 Agent（Learning Agent）

**特点：**

- 能利用经验改善策略
- 含反馈循环

如强化学习（RL Agent）。

### 4.4 多 Agent 系统（Multi-Agent System）

多个 Agent 合作，各司其职。

**如：**

- 研究代写团队（搜索 Agent、结构化 Agent、写作 Agent）
- 企业自动化系统

## 5. 初学者最关心的问题

### 5.1 Agent 一定要用大模型吗？

**不是，但大模型让 Agent 更强。**

以前 Agent 靠规则和状态机，现在靠 LLM（GPT、Claude 等）做决策更灵活。

### 5.2 Agent 和 LLM 是什么关系？

- **LLM 是"智能大脑"**
- **Agent 是"会动的大脑 + 身体"**

LLM 本身不是 Agent，它没有行动能力。

但当你给它：

- 工具
- 记忆
- 环境反馈

它就变成 Agent。

### 5.3 我需要多少基础知识才能开始写一个 Agent？

**最低门槛：**

- 会写 prompt
- 会调用一个 API（或工具）
- 懂任务分解（LLM 会帮你做）

现代 Agent 框架把难的都封装掉了。
