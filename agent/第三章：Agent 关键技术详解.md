## 3.1 Prompt 工程（Agent 行为的定义）

Prompt 工程是 Agent 的"人格与工作方式基准"。

### 1）Prompt 结构（核心模板）

一个成熟的 Agent Prompt 通常包含：

- **你是谁**（角色）  
- **你能做什么**（能力）  
- **你不能做什么**（限制）  
- **你要如何思考**（推理方式）  
- **你该如何行动**（输出规范）  
- **工具使用说明**  
- **失败与异常处理规则**  

这是定义 Agent 行为的制度文件（Policy）。

### 2）两类 Prompt

**类型 A：静态角色 Prompt**

如客服、客服知识库机器人。

**类型 B：动态 Agent Prompt**

包括工具使用、规划、反思指导。

动态 Prompt 是现代 Agent 的核心。

### 3）Prompt 的重要性

- 决定 Agent 是否稳健
- 决定 Agent 是否能正确工具调用
- 决定 Agent 是否会产生幻觉
- 决定 Agent 的思维链质量

**Prompt 工程 = Agent 的规则系统。**

---

## 3.2 工具使用（Tool Use）

工具使用是现代 Agent 能力的本质表现：

当它无法仅靠语言解决问题时，它必须调用外部能力。

### 工具类型包括：

#### 1）检索工具（Search）

- 搜索引擎
- 文档库
- 数据库查询
- 向量检索（RAG）

用于知识获取。

#### 2）思考工具（Reasoning Tools）

- 数学计算
- 代码运行
- 数据分析
- 模型调用（如图像识别）

让 Agent 擅长处理结构化问题。

#### 3）行动工具（Action Tools）

- 文件系统
- 浏览器自动化
- 应用控制（如 Slack、Notion、Google Drive 工具）

使 Agent 不是"说话机器人"，而是真正执行任务。

---

## 3.3 工具调用的流程（ReAct Tool Pattern）

工具调用遵循通用流程：

1. **Thought**（我现在应该做什么？）
2. **Action**（选择工具）
3. **Action Input**（工具参数）
4. **Observation**（工具返回结果）
5. 然后再次 **Thought**…

**示意：**

```
Thought: 我需要查询该公司的财报。
Action: search_api
Action Input: "公司名 + 财报"
Observation: 返回搜索结果
Thought: 我将从结果中提取财务数据...
```

这是现代 Agent 的通用标准。

## 3.4 规划（Planning）——长任务的必备能力

规划指的是：

将宏大目标拆分成具体子任务，并按序执行。

### 典型模型：

- Plan-and-Execute
- Plan-and-Act
- Plan-Refine-Execute

### 规划类型：

#### 1）静态规划（一次性生成完整计划）

**适用于：**

- 文章写作
- 报告生成
- 数据处理流程

**优点：** 结构好

**缺点：** 遇到意外需重规划

#### 2）动态规划（随执行随调整）

**适用于：**

- 搜索
- 工具调用
- 自动化任务

**优点：** 灵活

**缺点：** 推理成本高

### 规划流程示例：

**目标：** 做市场调研报告

**Plan:**

1. 明确定义行业与报告范围
2. 搜集公开数据
3. 整理结构化信息
4. 生成报告草稿
5. 优化报告并输出

规划让 Agent "可执行复杂项目"。

## 3.5 反思机制（Reflection）——让 Agent 变得更聪明

反思是现代 Agent 的突破能力，包括：

### 1）自我检视（Self-Critique）

Agent 自动检查自己的回答是否合理。

**例如：**

- **限制检查：** 我有没有违反规则？
- **逻辑检查：** 步骤是否合理？
- **工具检查：** 是否调用了正确工具？

### 2）错误恢复（Error Recovery）

当工具调用失败：

```
Observation: 错误：网络问题
Thought: 我将重试或选择备用工具
```

### 3）结果优化（Self-Refine）

Agent 可以对初稿自动完善，例如：

- 重构写作
- 优化代码
- 精炼结构

这种能力非常接近"思考第二遍"。

---

## 3.6 自主性（Autonomy）

自主性是 Agent 与普通 ChatGPT 最大区别。

### 具备自主性意味着 Agent 能：

#### 1）自己决定下一步

不是被动执行，而是主动思考。

#### 2）根据环境变化调整策略

**例如：**

- 搜索失败 → 换数据源
- API 超时 → 降级策略
- 数据不够 → 请求补充信息

#### 3）自己判断任务是否完成

**例如看到：**

- 已收集足够证据
- 工具结果不再更新
- 决策达到目标

自主性让 Agent 系统从"助手"变成"协作伙伴"。

---

## 3.7 Agent 的三种循环模式（核心工作流）

### 循环 1：ReAct（推理-行动循环）

**适合：**

- 工具调用
- 搜索任务
- 动态环境

**特点：** 强适应性。

### 循环 2：Plan-and-Execute

**适合：**

- 长文本任务
- 报告写作
- 编程任务

**特点：** 结构稳定。

### 循环 3：Reflection Loop（反思循环）

**流程：**

```
初稿 → 自我评估 → 修正 → 优化 → 完成
```

**适合：**

- 高质量输出
- 多步推理
- 复杂项目
