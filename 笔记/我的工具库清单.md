## 🤖 Agent 框架

### ✅ Agno
**状态**：已使用 | **项目**：practice7-ai_blog_to_podcast_agent  
**版本**：>=2.2.10  
**GitHub**：https://github.com/phidatahq/agno  
**使用体验**：
- ✅ API 简洁，上手快
- ✅ 工具集成方便（如 FirecrawlTools）
- ✅ 性能好，微秒级实例化
- ✅ 支持多种模型（OpenAI、Anthropic 等）
- ⚠️ 文档相对较少，社区较小

**适用场景**：
- 轻量级 Agent 应用
- 需要快速原型开发
- 高性能要求

**代码示例**：
```python
from agno.agent import Agent
from agno.models.openai import OpenAIChat
from agno.tools.firecrawl import FirecrawlTools

agent = Agent(
    name="Blog Summarizer",
    model=OpenAIChat(id="gpt-4o"),
    tools=[FirecrawlTools()],
    instructions=["..."],
)
```

## 🎙️ 文本转语音（TTS）

### ✅ ElevenLabs
**状态**：已使用 | **项目**：practice7-ai_blog_to_podcast_agent  
**类型**：API 服务  
**官网**：https://elevenlabs.io  
**使用体验**：
- ✅ 语音质量高，自然流畅
- ✅ 支持多语言（包括中文）
- ✅ API 简单易用
- ✅ 支持流式生成
- ⚠️ 需要 API Key，有成本
- ⚠️ Windows 安装路径长度限制（需用 `--user` 安装）

**适用场景**：
- 播客生成
- 语音助手
- 多语言 TTS 需求

**代码示例**：
```python
from elevenlabs import ElevenLabs

client = ElevenLabs(api_key=api_key)
audio_generator = client.text_to_speech.convert(
    text=text,
    voice_id="JBFqnCBsd6RMkjVDRZzb",
    model_id="eleven_multilingual_v2"
)
```

## 📚 学习资源

### 发现工具的方法
1. **官方文档**：查看框架推荐的工具列表
2. **GitHub**：搜索 `awesome-[领域]` 列表
3. **社区**：Reddit、Hacker News、Stack Overflow
4. **项目依赖**：查看相关项目的 `requirements.txt`

### 评估工具的标准
- ✅ **易用性**：API 是否简洁
- ✅ **功能**：是否满足需求
- ✅ **维护**：是否活跃更新
- ✅ **成本**：是否免费/开源
- ✅ **性能**：是否足够快
- ✅ **文档**：文档是否完善
- ✅ **社区**：社区是否活跃

## 💡 经验总结

1. **先搜索，再动手**：花 30 分钟搜索可能节省数小时开发时间
2. **从简单开始**：先用最简单的方案，不够用时再升级
3. **关注活跃度**：GitHub Stars、最近提交、Issue 响应速度
4. **参考成功案例**：看类似项目用了什么库
5. **建立反馈循环**：记录使用体验，更新清单
