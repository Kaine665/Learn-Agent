# 工作流生成系统设计：规则查询-模式学习-智能生成-渐进演进

## 核心设计理念

### 四个核心功能

工作流生成系统应该具备四个核心能力：

1. **规则查询（快速、准确）** - 快速查找已有工作流
2. **模式学习（积累知识）** - 从工作流中提取行业模式
3. **智能生成（为新用户服务）** - 基于模式生成新工作流
4. **渐进式演进（自动优化）** - 系统自动学习和改进

### 设计目标

**核心问题：**
- 行业隐性知识难以获取和保存
- 新用户需要从零开始构建工作流
- 工作流是公司内部财产，但行业模式可以共享

**解决方案：**
- 通过规则查询快速复用已有工作流
- 通过模式学习积累行业知识
- 通过智能生成为新用户提供基础模板
- 通过渐进式演进持续优化系统

## 一、规则查询（快速、准确）

### 1.1 设计目标

- **快速**：毫秒级查询响应
- **准确**：精确匹配用户需求
- **可扩展**：支持大量工作流存储

### 1.2 架构设计

```python
class WorkflowRuleManager:
    """工作流规则管理器：快速查询"""
    
    def __init__(self):
        # 工作流存储
        self.workflows: Dict[str, Workflow] = {}
        
        # 多维度索引
        self.index_by_industry: Dict[str, List[str]] = {}  # 行业索引
        self.index_by_type: Dict[str, List[str]] = {}     # 类型索引
        self.index_by_tags: Dict[str, List[str]] = {}      # 标签索引
        self.index_composite: Dict[Tuple[str, str], List[str]] = {}  # 复合索引
        
        # 元数据索引（用于高级查询）
        self.metadata_index: Dict[str, Any] = {}
    
    def find_workflow(
        self, 
        industry: Optional[str] = None,
        workflow_type: Optional[str] = None,
        tags: Optional[List[str]] = None,
        **kwargs
    ) -> List[Workflow]:
        """多维度查询工作流"""
        candidates = set()
        
        # 1. 行业查询
        if industry:
            candidates.update(self.index_by_industry.get(industry, []))
        
        # 2. 类型查询
        if workflow_type:
            type_candidates = self.index_by_type.get(workflow_type, [])
            if candidates:
                candidates &= set(type_candidates)
            else:
                candidates.update(type_candidates)
        
        # 3. 标签查询
        if tags:
            tag_candidates = set()
            for tag in tags:
                tag_candidates.update(self.index_by_tags.get(tag, []))
            if candidates:
                candidates &= tag_candidates
            else:
                candidates.update(tag_candidates)
        
        # 4. 评分排序
        workflows = [self.workflows[wid] for wid in candidates]
        return self._rank_workflows(workflows, **kwargs)
    
    def _rank_workflows(
        self, 
        workflows: List[Workflow], 
        **criteria
    ) -> List[Workflow]:
        """根据标准对工作流排序"""
        scored = []
        for workflow in workflows:
            score = self._calculate_score(workflow, **criteria)
            scored.append((score, workflow))
        
        scored.sort(key=lambda x: x[0], reverse=True)
        return [w for _, w in scored]
    
    def _calculate_score(self, workflow: Workflow, **criteria) -> float:
        """计算工作流匹配分数"""
        score = 0.0
        
        # 使用频率权重
        score += workflow.usage_count * 0.3
        
        # 成功率权重
        score += workflow.success_rate * 0.4
        
        # 最近更新时间权重
        recency_score = self._calculate_recency(workflow.updated_at)
        score += recency_score * 0.3
        
        return score
```

## 二、模式学习（积累知识）

### 2.1 设计目标

- **提取行业模式**：从多个工作流中提取通用模式
- **保护隐私**：只提取模式，不保留公司特定信息
- **持续学习**：随着数据积累不断优化模式

### 2.2 架构设计

```python
class WorkflowPatternLearner:
    """工作流模式学习器"""
    
    def __init__(self):
        # 训练数据
        self.training_samples: List[WorkflowSample] = []
        
        # 学习到的模式
        self.patterns: Dict[str, WorkflowPattern] = {}  # industry -> pattern
        
        # 学习配置
        self.min_samples_for_pattern = 5  # 最少样本数
        self.confidence_threshold = 0.7    # 置信度阈值
    
    def collect_sample(self, workflow: Workflow):
        """收集工作流样本（匿名化）"""
        # 匿名化处理：去除公司特定信息
        sample = self._anonymize_workflow(workflow)
        self.training_samples.append(sample)
        
        # 检查是否达到学习阈值
        industry_samples = [
            s for s in self.training_samples 
            if s.industry == workflow.industry
        ]
        
        if len(industry_samples) >= self.min_samples_for_pattern:
            self.learn_pattern(workflow.industry)
    
    def _anonymize_workflow(self, workflow: Workflow) -> WorkflowSample:
        """匿名化工作流，只保留模式信息"""
        return WorkflowSample(
            industry=workflow.industry,
            workflow_type=workflow.workflow_type,
            
            # 提取步骤模式（抽象化）
            step_patterns=self._extract_step_patterns(workflow.steps),
            
            # 提取决策规则模式
            decision_patterns=self._extract_decision_patterns(
                workflow.decision_points
            ),
            
            # 提取协作模式
            collaboration_pattern=self._extract_collaboration_pattern(
                workflow.collaboration_pattern
            ),
            
            # 不包含公司特定信息
            metadata={}  # 只保留通用元数据
        )
    
    def learn_pattern(self, industry: str):
        """学习行业工作流模式"""
        # 获取该行业的所有样本
        industry_samples = [
            s for s in self.training_samples 
            if s.industry == industry
        ]
        
        if len(industry_samples) < self.min_samples_for_pattern:
            return
        
        # 1. 提取通用步骤模式
        common_steps = self._find_common_steps(industry_samples)
        
        # 2. 提取决策规则模式
        decision_rules = self._extract_decision_rule_patterns(industry_samples)
        
        # 3. 提取协作模式
        collaboration_patterns = self._extract_collaboration_patterns(
            industry_samples
        )
        
        # 4. 计算模式置信度
        confidence = self._calculate_confidence(
            industry_samples, 
            common_steps, 
            decision_rules
        )
        
        # 5. 保存模式
        pattern = WorkflowPattern(
            industry=industry,
            common_steps=common_steps,
            step_templates=self._create_step_templates(common_steps),
            decision_rules=decision_rules,
            collaboration_patterns=collaboration_patterns,
            confidence=confidence,
            sample_count=len(industry_samples),
            learned_at=datetime.now().isoformat()
        )
        
        self.patterns[industry] = pattern
    
    def _find_common_steps(
        self, 
        samples: List[WorkflowSample]
    ) -> List[StepPattern]:
        """找到通用步骤模式"""
        # 统计步骤频率
        step_frequency = {}
        for sample in samples:
            for step_pattern in sample.step_patterns:
                step_key = self._normalize_step(step_pattern)
                step_frequency[step_key] = step_frequency.get(step_key, 0) + 1
        
        # 提取高频步骤（出现频率 > 阈值）
        threshold = len(samples) * self.confidence_threshold
        common_steps = [
            step for step, freq in step_frequency.items()
            if freq >= threshold
        ]
        
        # 按频率排序
        common_steps.sort(key=lambda s: step_frequency[s], reverse=True)
        
        return common_steps
    
    def _extract_decision_rule_patterns(
        self, 
        samples: List[WorkflowSample]
    ) -> List[DecisionRulePattern]:
        """提取决策规则模式"""
        # 统计决策规则频率
        rule_frequency = {}
        for sample in samples:
            for rule_pattern in sample.decision_patterns:
                rule_key = self._normalize_rule(rule_pattern)
                rule_frequency[rule_key] = rule_frequency.get(rule_key, 0) + 1
        
        # 提取高频规则
        threshold = len(samples) * self.confidence_threshold
        common_rules = [
            rule for rule, freq in rule_frequency.items()
            if freq >= threshold
        ]
        
        return common_rules
```

### 2.4 学习算法

**模式提取流程：**
1. **数据收集**：收集匿名化的工作流样本
2. **特征提取**：提取步骤、决策规则、协作模式
3. **频率分析**：统计特征出现频率
4. **模式识别**：识别高频特征作为模式
5. **置信度计算**：计算模式置信度
6. **模式保存**：保存学习到的模式

**学习触发条件：**
- 样本数量达到阈值（如：5个样本）
- 定期批量学习（如：每天一次）
- 手动触发学习

## 三、智能生成（为新用户服务）

### 3.1 设计目标

- **快速生成**：为新用户快速生成基础工作流
- **基于模式**：基于学习到的行业模式生成
- **可定制化**：支持用户微调和定制

### 3.2 架构设计

```python
class WorkflowGenerator:
    """工作流生成器：基于模式生成新工作流"""
    
    def __init__(self, pattern_learner: WorkflowPatternLearner):
        self.pattern_learner = pattern_learner
    
    def generate_workflow(
        self, 
        industry: str,
        workflow_type: str,
        requirements: Dict[str, Any],
        customization: Optional[Dict[str, Any]] = None
    ) -> Workflow:
        """基于行业模式生成工作流"""
        
        # 1. 获取行业模式
        pattern = self.pattern_learner.get_pattern(industry)
        
        if not pattern:
            # 如果没有模式，使用通用模板
            return self._generate_generic_workflow(
                industry, 
                workflow_type, 
                requirements
            )
        
        # 2. 基于模式生成工作流步骤
        steps = self._generate_steps_from_pattern(
            pattern, 
            requirements
        )
        
        # 3. 生成决策点
        decision_points = self._generate_decision_points(
            pattern, 
            requirements
        )
        
        # 4. 生成协作模式
        collaboration_pattern = self._generate_collaboration_pattern(
            pattern, 
            requirements
        )
        
        # 5. 应用用户定制
        if customization:
            steps = self._apply_customization(steps, customization)
            decision_points = self._apply_customization(
                decision_points, 
                customization
            )
        
        # 6. 创建工作流
        workflow = Workflow(
            id=self._generate_id(),
            industry=industry,
            workflow_type=workflow_type,
            name=requirements.get("name", f"{industry}工作流"),
            description=requirements.get("description", ""),
            steps=steps,
            decision_points=decision_points,
            collaboration_pattern=collaboration_pattern,
            tags=requirements.get("tags", []),
            metadata=requirements.get("metadata", {}),
            created_at=datetime.now().isoformat(),
            updated_at=datetime.now().isoformat()
        )
        
        return workflow
    
    def _generate_steps_from_pattern(
        self, 
        pattern: WorkflowPattern,
        requirements: Dict[str, Any]
    ) -> List[WorkflowStep]:
        """基于模式生成步骤"""
        steps = []
        
        for step_name in pattern.common_steps:
            # 获取步骤模板
            template = pattern.step_templates.get(step_name)
            
            if template:
                # 基于模板创建步骤
                step = self._create_step_from_template(
                    template, 
                    requirements
                )
            else:
                # 创建基础步骤
                step = WorkflowStep(
                    name=step_name,
                    description=f"{step_name}步骤",
                    action="custom",
                    config={}
                )
            
            steps.append(step)
        
        return steps
    
    def _generate_decision_points(
        self,
        pattern: WorkflowPattern,
        requirements: Dict[str, Any]
    ) -> List[DecisionPoint]:
        """基于模式生成决策点"""
        decision_points = []
        
        for rule_pattern in pattern.decision_rules:
            decision_point = self._create_decision_point_from_pattern(
                rule_pattern,
                requirements
            )
            decision_points.append(decision_point)
        
        return decision_points
    
    def _generate_generic_workflow(
        self,
        industry: str,
        workflow_type: str,
        requirements: Dict[str, Any]
    ) -> Workflow:
        """生成通用工作流（无模式时）"""
        # 使用通用模板
        generic_steps = self._get_generic_steps(workflow_type)
        
        workflow = Workflow(
            id=self._generate_id(),
            industry=industry,
            workflow_type=workflow_type,
            name=requirements.get("name", f"{industry}工作流"),
            description=requirements.get("description", ""),
            steps=generic_steps,
            decision_points=[],
            collaboration_pattern=None,
            tags=requirements.get("tags", []),
            metadata=requirements.get("metadata", {}),
            created_at=datetime.now().isoformat(),
            updated_at=datetime.now().isoformat()
        )
        
        return workflow
```

## 四、渐进式演进（自动优化）

### 4.1 设计目标

- **自动学习**：系统自动从新数据中学习
- **持续优化**：不断改进模式和生成质量
- **反馈循环**：用户反馈驱动系统改进

### 4.2 架构设计

```python
class WorkflowSystem:
    """工作流系统：整合所有功能"""
    
    def __init__(self):
        # 四个核心组件
        self.rule_manager = WorkflowRuleManager()
        self.pattern_learner = WorkflowPatternLearner()
        self.workflow_generator = WorkflowGenerator(self.pattern_learner)
        self.evolution_engine = EvolutionEngine()
    
    def save_workflow(self, workflow: Workflow):
        """保存工作流（触发学习）"""
        # 1. 保存到规则库
        self.rule_manager.save_workflow(workflow)
        
        # 2. 收集训练样本
        self.pattern_learner.collect_sample(workflow)
        
        # 3. 检查是否需要重新学习
        if self._should_relearn(workflow.industry):
            self.pattern_learner.learn_pattern(workflow.industry)
            
            # 4. 评估模式质量
            self.evolution_engine.evaluate_pattern(
                workflow.industry
            )
    
    def generate_workflow(
        self,
        industry: str,
        workflow_type: str,
        requirements: Dict[str, Any]
    ) -> Workflow:
        """生成工作流（收集反馈）"""
        # 1. 生成工作流
        workflow = self.workflow_generator.generate_workflow(
            industry,
            workflow_type,
            requirements
        )
        
        # 2. 记录生成历史（用于反馈）
        self.evolution_engine.record_generation(
            industry,
            workflow_type,
            workflow.id
        )
        
        return workflow
    
    def record_feedback(
        self,
        workflow_id: str,
        feedback: Dict[str, Any]
    ):
        """记录用户反馈（驱动演进）"""
        # 1. 记录反馈
        self.evolution_engine.record_feedback(workflow_id, feedback)
        
        # 2. 分析反馈
        analysis = self.evolution_engine.analyze_feedback(workflow_id)
        
        # 3. 如果反馈负面，触发优化
        if analysis["needs_improvement"]:
            self._trigger_optimization(workflow_id, analysis)
    
    def _should_relearn(self, industry: str) -> bool:
        """判断是否需要重新学习"""
        # 检查样本数量变化
        current_samples = len([
            s for s in self.pattern_learner.training_samples
            if s.industry == industry
        ])
        
        pattern = self.pattern_learner.patterns.get(industry)
        if not pattern:
            return current_samples >= 5
        
        # 如果样本数量显著增加，重新学习
        return current_samples >= pattern.sample_count * 1.5

class EvolutionEngine:
    """演进引擎：自动优化系统"""
    
    def __init__(self):
        self.feedback_history: List[FeedbackRecord] = []
        self.generation_history: List[GenerationRecord] = []
        self.optimization_log: List[OptimizationRecord] = []
    
    def evaluate_pattern(self, industry: str):
        """评估模式质量"""
        pattern = self.pattern_learner.patterns.get(industry)
        if not pattern:
            return
        
        # 评估指标
        metrics = {
            "confidence": pattern.confidence,
            "sample_count": pattern.sample_count,
            "usage_frequency": self._calculate_usage_frequency(industry),
            "success_rate": self._calculate_success_rate(industry)
        }
        
        # 如果质量下降，触发优化
        if metrics["confidence"] < 0.6:
            self._optimize_pattern(industry, metrics)
    
    def _optimize_pattern(self, industry: str, metrics: Dict):
        """优化模式"""
        # 1. 分析问题
        issues = self._identify_issues(industry, metrics)
        
        # 2. 调整学习参数
        if "low_confidence" in issues:
            self.pattern_learner.confidence_threshold = 0.6
        
        # 3. 重新学习
        self.pattern_learner.learn_pattern(industry)
        
        # 4. 记录优化
        self.optimization_log.append(
            OptimizationRecord(
                industry=industry,
                issues=issues,
                actions_taken=["lowered_confidence_threshold", "relearned"],
                timestamp=datetime.now().isoformat()
            )
        )
```

4. **定期检查**：定期评估和优化

**优化策略：**
1. **参数调整**：调整学习参数

3. **模式合并**：合并相似模式
4. **模式拆分**：拆分过于宽泛的模式

**反馈循环：**
```
用户使用工作流

    ↓
收集用户反馈
    ↓
分析反馈数据
    ↓
触发系统优化
    ↓
更新模式和生成器
    ↓
生成更好的工作流
```

### 5.3 API设计

```python
class WorkflowSystemAPI:
    """工作流系统API"""
    
    # 规则查询
    def find_workflows(
        self,
        industry: Optional[str] = None,
        workflow_type: Optional[str] = None,
        **kwargs
    ) -> List[Workflow]:
        """查询工作流"""
        return self.rule_manager.find_workflow(
            industry, workflow_type, **kwargs
        )
    
    # 保存工作流
    def save_workflow(self, workflow: Workflow):
        """保存工作流（触发学习）"""
        self.system.save_workflow(workflow)
    
    # 生成工作流
    def generate_workflow(
        self,
        industry: str,
        workflow_type: str,
        requirements: Dict[str, Any]
    ) -> Workflow:
        """生成新工作流"""
        return self.system.generate_workflow(
            industry, workflow_type, requirements
        )
    
    # 获取模式
    def get_pattern(self, industry: str) -> Optional[WorkflowPattern]:
        """获取行业模式"""
        return self.pattern_learner.get_pattern(industry)
    
    # 反馈
    def submit_feedback(
        self,
        workflow_id: str,
        feedback: Dict[str, Any]
    ):
        """提交反馈（驱动演进）"""
        self.system.record_feedback(workflow_id, feedback)
```

## 七、关键设计决策

### 7.1 隐私保护

**决策：** 匿名化处理，只提取模式信息

**理由：**
- 保护公司内部财产
- 只共享行业通用模式
- 平衡隐私和知识共享

### 7.2 模式学习阈值

**决策：** 最少5个样本才开始学习模式

**理由：**
- 样本太少，模式不可靠
- 样本太多，学习延迟
- 5个样本是平衡点

### 7.3 渐进式学习

**决策：** 样本数量增加50%时重新学习

**理由：**
- 避免频繁重新学习
- 及时更新模式
- 平衡性能和准确性

### 7.4 生成策略

**决策：** 优先使用模式，无模式时使用通用模板

**理由：**
- 模式生成质量更高
- 通用模板保证可用性
- 渐进式改进
